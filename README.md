# Ankira

Ankira is a JavaFX-based music player and media library inspired by modern streaming apps. It provides a local music experience with a dark-themed interface, track browsing, search, playlist management, and a player bar for playback controls.

## Features

- Search songs by name or artist
- Browse a music library organized as a dynamic collection of cards
- Play audio tracks from bundled local resources
- Manage playlist entries from the music grid
- Switch between home/library-style views in a side navigation UI
- Custom JavaFX styling with a polished dark theme

## Tech stack

- Java 17
- Gradle
- JavaFX 21
- JavaFX Media for audio playback
